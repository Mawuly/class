# Campus footage

The landing page picks a loop by the visitor's clock: morning (before 12:00), afternoon (12:00–17:00), evening.
Put these files here; until they exist the page shows a plain timetable-grid background.

| File | What |
|---|---|
| `campus-morning.mp4` / `.webm` / `.jpg` | Morning loop and its poster still |
| `campus-afternoon.mp4` / `.webm` / `.jpg` | Afternoon loop and poster |
| `campus-evening.mp4` / `.webm` / `.jpg` | Evening loop and poster |

- 15–25 second seamless loops, 1080p, ~4–6 MB each. H.264 MP4 and VP9 WebM, no audio track.
- Grade as a duotone in your editor (shadows → Ink `#12161C`, highlights → Bone `#EDE6DA`); the page applies no filter.
- Film wide and soft, so people are part of the scene rather than recognisable faces.
- Phones and Data Saver users get only the `.jpg` still.
